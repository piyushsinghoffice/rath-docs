Use Settings to choose how Rath handles messages, context and tools. For a specific task, start with the linked guide; use these tables when you need the available values and defaults.

1. Open **Settings**.
2. Select **AI**, then the section named below. Search for the setting if you don't see it immediately.
3. Choose a value or switch a setting on or off. The chosen value is shown in Settings. Some changes apply only to new chats, as noted below.

- [General](/rath-docs/settings-general/): starting models, message suggestions and inline completions.
- [Chat](/rath-docs/settings-chat/): message handling, notifications and the loading animation.
- [Context](/rath-docs/settings-context/): retaining details and notes over long conversations.
- [Tools](/rath-docs/settings-tools/): connected services, web search and finding abilities.
- [Rath Features](/rath-docs/settings-features/): switches for displays, appearance and notes.

The default is the value registered by Rath. A choice you or your organization made can change what you see. For a walkthrough of choosing an AI model, see [Models and thinking level](/rath-docs/models/); for safety choices, see [Permissions](/rath-docs/permissions/).

If a setting appears to have no effect, check whether it requires a new chat or a particular permission mode. If a provider needs a key, set it up before trying the feature. See [Troubleshooting](/rath-docs/troubleshooting/).
